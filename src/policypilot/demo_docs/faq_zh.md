# 示例保险常见问题（虚构演示文档）

本文件是为 PolicyPilot 演示编写的虚构内容，不是真实的保险合同。

## 重复保险

如果同一保险标的在多家保险公司重复投保，发生保险事故时，本公司按照本保险合同的保险金额与所有保险合同保险金额总和的比例承担赔偿责任。任何情况下，总赔偿金额不超过实际损失。

## 续保与保险期间

保险期间届满后，如投保人未在保险期间届满后三十日内交纳续保保险费，本合同自动终止，需要重新投保。

## 等待期

健康保险附加险自合同生效之日起有三十日的等待期。等待期内发生的疾病不属于保险责任，意外伤害不受等待期限制。

## 理赔时效

被保险人应在知道保险事故发生之日起十日内通知保险公司。索赔所需材料包括理赔申请书、身份证明、事故证明和费用发票。
